# خطة خلف — 20 يوم للوزاري 🚀

تطبيق ويب حديث، سريع، واحترافي لإدارة خطة الدراسة المكثفة للامتحانات الوزارية خلال 20 يومًا (من 7/8 إلى 26/8).

التطبيق مصمم خصيصًا ليعمل بدون إنترنت (Offline-First) بحفظ التقدم تلقائيًا في `LocalStorage` مع واجهة كاملة باللغة العربية بأسلوب متجاوب ممتاز للهواتف الذكية ومناسب جدًا للتحويل المباشر إلى تطبيق Android/iOS عبر منصة **Median** (WebView).

---

## 📱 مميزات التطبيق

- **التركيز على مهام اليوم**: عرض سريع لمهام اليوم مع شريط تقدم كلي ومتبقي الأيام.
- **بطاقة اليوم التفاعلية**: قائمة تفقدية (Checkboxes) لكل مادة (الفيزياء ⚡، الكيمياء 🧪، الرياضيات 🧮، اللغة العربية 📚).
- **متابعة إنجاز المواد**: حاسبة تلقائية لنسبة إنجاز كل مادة من المواد الأربعة.
- **صفحة الجدول الكاملة**: استعراض الأيام الـ 20 بالكامل (7/8 - 26/8) مع خيار الانتقال السريع.
- **نظام الالتزام المتتالي (Streak 🔥)**: احتساب أيام الالتزام المتتابعة فور إكمال مهام اليوم.
- **صفحة الإحصائيات الشاملة**: كشف نسب الإنجاز، عدد المهام المكتملة والمتبقية، وتحديد "أكثر مادة متأخر بها" تلقائيًا.
- **تخصيص المظهر**: دعم الوضع الداكن (Dark Mode) افتراضيًا والوضع الفاتح (Light Mode).
- **أمان البيانات**: حفظ جميع البيانات في ذاكرة متصفح الهاتف (`LocalStorage`) بدون الحاجة إلى تسجيل دخول أو سيرفر أو خادم خارجي.
- **التصميم والدقة**: مراجعة شاملة للمناهج (مع استبعاد الفصل الثالث للرياضيات المحذوف نهائيًا، واستبعاد أي يوم بعد 26/8).

## 🛠️ متطلبات التشغيل

- Node.js (الإصدار 18 أو أحدث)
- npm أو yarn

---

## 🚀 طريقة التشغيل محليًا (Local Development)

1. **تثبيت الحزم والمكتبات**:
   ```bash
   npm install
   ```

2. **تشغيل سيرفر التطوير**:
   ```bash
   npm run dev
   ```

3. افتح المتصفح على الرابط الموضح في التيرمينال (عادة `http://localhost:3000`).

---

## 📦 طريقة البناء والإنتاج (Build)

لإنشاء النسخة النهائية الجاهزة والنظيفة للنشر:

```bash
npm run build
```

سيتولد مجلد باسم `dist/` يحتوي على كامل ملفات Web App الجاهزة للنشر.

## 🐙 1. طريقة رفع المشروع إلى GitHub

1. أنشئ مستودعًا جديدًا (New Repository) على [GitHub](https://github.com) باسم `khalaf-study-plan`.
2. في التيرمينال داخل مجلد المشروع نفّذ الأوامر التالية:

```bash
git init
git add .
git commit -m "المشروع الأول: خطة خلف 20 يوم للوزاري"
git branch -M main
git remote add origin https://github.com/USERNAME/khalaf-study-plan.git
git push -u origin main
```
*(استبدل `USERNAME` باسم حسابك في GitHub)*

---

## 🌐 2. طريقة النشر على Netlify

1. سجل الدخول إلى [Netlify](https://app.netlify.com/).
2. اضغط على **Add new site** ثم اختر **Import an existing project**.
3. اختر **GitHub** وحدد مستودع `khalaf-study-plan`.
4. تأكد من الإعدادات التالية (يقرأها Netlify تلقائيًا من ملف `netlify.toml` المرفق):
   - **Build Command**: `npm run build`
   - **Publish directory**: `dist`
5. اضغط **Deploy Site**.
6. ستحصل خلال ثوانٍ على رابط موقعك المجاني والنظيف (مثال: `https://khalaf-plan-2026.netlify.app`).

---

## 📱 3. طريقة تحويل الموقع إلى تطبيق Android / iOS باستخدام Median

1. اذهب إلى موقع [Median.co](https://median.co/).
2. في خانة **App URL**، أدخل رابط موقعك منشورًا على Netlify (مثال: `https://khalaf-plan-2026.netlify.app`).
3. أدخل اسم التطبيق: `خطة خلف`.
4. في قسم **Style & UI**:
   - فعّل خيار **Hide Navigation Bar** أو استخدم الشاشة الكاملة.
   - المظهر يتكيف تلقائيًا مع أبعاد وشاشات الهواتف بفضل تصميم Mobile-First.
5. اضغط **Build App** لتحميل ملف الـ APK الخاص بنظام Android أو ملف iOS للتثبيت على الموبايل!
